# Quantmetrics Project Context

## 1. Project Overview
- Quantmetrics-Lab (quantmetrics.online) is an AI-powered data-analysis and research lab for quantitative finance and econometric studies. It turns market noise into clear, actionable insights. All content is research and education only, never investment advice.
- Development stage: all eleven build stages are complete, plus a launch-readiness pass (stage 12). Done: Stage 1 tokens/theming/styleguide, Stage 2 base UI, Stage 3 header, Stage 4 footer, Stage 5 home hero, Stage 6a home capabilities + audience tabs, Stage 6b home feature trio / sample data / latest briefs / analytics band, Stage 7 Services page, Stage 8 Blog (index, article page, reusable ArticleLayout, MDX + KaTeX pipeline), Stage 9 Insights (index, brief detail page reusing ArticleLayout, AI brief content layer), Stage 10 Contact (validated form + stub API route) and Auth (mocked split-screen sign-up / sign-in), Stage 11 About, Docs, legal, 404, error boundary and `/blog/learn`, and Stage 12 launch readiness (`robots.txt`, `sitemap.xml`, share image, single canonical-URL source).
- Every header and footer link resolves to real content. Two flows remain deliberate stubs and are the only unfinished *behaviour*: the contact endpoint delivers nothing, and auth is mocked. See Pending / Next Steps.

## 2. Tech Stack
- Framework: Next.js 16.4 (App Router, Turbopack) with React 19.3 and TypeScript 5.
- Styling: Tailwind CSS v4 via the `@tailwindcss/turbopack` plugin. CSS-first, so there is no `tailwind.config.ts`; the theme is mapped in `src/app/globals.css` (`@theme inline`).
- Charting: ECharts 6. Fonts are **self-hosted from `src/fonts/` through `next/font/local`** (Newsreader display serif, Inter Tight UI sans, JetBrains Mono): four latin variable woff2 files vendored into the repo, so nothing is fetched from fonts.googleapis.com at build time or at runtime (the machine cannot reach it). `layout.tsx` keeps the same `--font-newsreader` / `--font-inter-tight` / `--font-jetbrains-mono` variables, weight ranges (`200 800` / `100 900` / `100 800`) and `display: swap`, and Next still generates metric-adjusted fallback faces (`Times New Roman` for the serif, `Arial` for the other two).
- Content: MDX files in `src/content/blog` and `src/content/briefs` with YAML frontmatter, read at build time by `gray-matter` (`src/lib/blog.ts`, `src/lib/briefs.ts`, shared helpers in `src/lib/content.ts`) and compiled to React by `@mdx-js/mdx` (`compile` + `run`, server-only). Maths renders through KaTeX 0.19: `preprocessMath` rewrites `$...$` / `$$...$$` into JSX *before* MDX parses, because markdown would otherwise split formulas on `_`, `^` and `[`. `@next/mdx` was removed; `@mdx-js/mdx` is an explicit dependency.
- Tooling: ESLint 9 with `eslint-config-next@16.4.0`, aligned to the installed Next 16.4.0 so `npm run lint` exits 0 (the previous `14.2.35` had no flat-config entry point and crashed the run). Scripts: `dev`, `build`, `start`, `lint`, `typecheck`, `verify:math`.

## 4. Design System & Critical UI Rules
- Source of truth is `src/styles/tokens.css`; dark is the default (`:root`), light overrides via `[data-theme="light"]` with a `prefers-color-scheme` no-JS fallback. Components must use mapped Tailwind utilities (`bg-bg-elev`), never hard-coded values.
- Surfaces: `--bg`, `--bg-elev`, `--bg-hover`, and `--surface-deep` (theme-invariant near-black for the Services hero).
- Hairlines: `--line` (soft), `--line-strong` (crisp, full-length blueprint line; never faded or masked, runs edge-to-edge into the corners), `--line-grid` (1px at 30% for ruled grid frames).
- Text levels: `--text`, `--text-muted`, `--text-dim`.
- Accents (identical in both themes): teal, periwinkle, coral, amber, lilac, plus positive/negative. Gradients are built only from accent tokens; `--on-gradient*` is the only literal white.
- Layout: 8px spacing base, 1530px container, gutters 16 to 24 to 32px, card radius 24px. Hover 150ms, card gradient fill 200ms, ease cubic-bezier(0.2, 0.8, 0.2, 1). The inline theme script sets `data-theme` before first paint (no flash).
- Typography: Newsreader display serif, Inter Tight UI sans, JetBrains Mono mono; responsive clamp scale (`text-hero`, `text-h2`, `text-article-title`) with tight negative tracking on display sizes.
